# 研途日记 · 考研学习日记

一个个人向的考研日记网站(计算机 11408:数学一 / 英语一 / 408),纯静态、零依赖、加载快。

**在线访问**:`https://jlshdsdk.github.io/kaoyan-diary/`

## 功能

- 📔 **日记(主功能)**:按日写日记,心情 + 标签打卡,自动保存,往期日记可搜索回看
- ⏱️ **学习时长统计**:数学 / 英语 / 408 三科分别记录分钟数,支持专注计时器、快捷 +15/+30/+60 或直接输入
- 🔥 **学习热力图**:GitHub 风格的过去一年热力图,点击任意日期即可跳转查看/补记
- 📊 **统计面板**:今日分钟数、本周小时数、连续打卡天数、累计小时、近 7 日柱状图、本周科目分布环图
- ⏳ **初试倒计时**:顶栏显示距考研初试天数(日期可在设置中修改)
- 👥 **多账号**:管理员可创建/重置/删除账号,每个账号日记与进度完全独立
- 📱 支持 PWA 安装到手机桌面,深浅双主题

## 多设备同步原理

站点是纯静态页面,数据保存在你自己的 **GitHub 私有仓库** `kaoyan-diary-data` 中:

1. 登录时,浏览器用你的密码在本地解密出 GitHub 令牌;
2. 所有读写通过 GitHub Contents API 直接在你的私有仓库进行;
3. 换任何设备,用同一账号密码登录即可同步全部进度。

## 安全模型

- **密码永远不会上传**:登录验证 = 用密码解密令牌(密码错 = 解密失败),服务端无密码、无明文;
- 令牌用「密码派生密钥(PBKDF2-SHA256 ×310000)+ AES-GCM」加密后存在公开仓库的 `accounts.json` 里,只有密文;
- 日记内容只存在私有仓库,公开渠道不可见;
- 因此请设置 **8 位以上**的密码。忘记密码可用「忘记密码」入口,凭一个新的有效令牌重置。

## 常见操作

| 操作 | 位置 |
| --- | --- |
| 创建/重置/删除账号 | 设置 → 账号管理(仅管理员) |
| 修改初试日期、每日目标 | 设置 → 学习偏好 |
| 导出/导入备份 | 设置 → 数据与令牌 |
| 更换 GitHub 令牌 | 设置 → 数据与令牌 |

## 令牌更换

若令牌过期或失效,在「设置 → 数据与令牌」粘贴新令牌即可。推荐细粒度令牌:
[github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new),
勾选 `kaoyan-diary` 与 `kaoyan-diary-data` 两个仓库,权限仅需 **Contents: Read and write**。
