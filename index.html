研途 · 每日一句

研途日记 · 数据加密同步于你的私有仓库 · 愿你合上笔盖的刹那,有侠客收剑入鞘的骄傲

欢迎使用「研途日记」🏗️

第一次使用需要 1 分钟初始化,之后在任何设备上只需账号 + 密码即可登录。

  • 📔 日记存在你自己的 GitHub 私有仓库(jlshdsdk/kaoyan-diary-data),别人无法查看;
  • 🔒 你的密码只用来在本机加密数据,不会上传,服务器也没有你的密码;
  • 🎫 需要一个 GitHub 令牌(Token)让网站代你读写数据仓库,只需配置一次,它会加密后保存;
  • 初始化后,你就是管理员,可以在「设置 → 账号管理」里为朋友创建独立账号。

① 创建管理员账号

这是你的最高权限账号,可以管理其他账号。

② 配置 GitHub 令牌

令牌只授权读写这两个仓库:kaoyan-diary(账号信息)与 kaoyan-diary-data(日记数据)。

推荐方式(权限最小):
  1. 打开 github.com/settings/personal-access-tokens/new
  2. Repository access 选 Only select repositories,勾选 kaoyan-diary 和 kaoyan-diary-data
  3. Permissions 中 Contents → Read and write,其余保持 No access
  4. 生成后复制 github_pat_ 开头的令牌,粘贴到下面
快捷方式(经典令牌,权限较大) 打开 生成经典令牌(已自动勾选 repo 权限),生成后粘贴到下面。

③ 完成 🎉

一切就绪!点击下面按钮完成初始化。

  • 令牌将用你的密码加密(AES-GCM)后保存,忘记密码可用「忘记密码」重新配置;
  • 日记数据保存在私有仓库,记得偶尔在「设置 → 数据」里导出备份。

重置账号(管理员恢复)

密码无法找回(它从不离开你的设备)。但只要重新提供一个有效令牌,即可重置管理员密码。
